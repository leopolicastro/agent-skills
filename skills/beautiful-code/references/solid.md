# SOLID Reference

Apply where the language and context support it. Flag violations as suggestions when fixing them requires structural changes beyond the current diff. Don't over-engineer small scripts.

- **Single Responsibility** — one reason to change per class or module
- **Open/Closed** — extend behavior without modifying existing code where practical
- **Liskov Substitution** — subtypes must honor the contract of what they replace
- **Interface Segregation** — don't force callers to depend on what they don't use
- **Dependency Inversion** — depend on abstractions, not concretions
